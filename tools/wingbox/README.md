# tools/wingbox — як малюємо зони (розкладка «по дузі», 3D, живі шари)

Зона кімнати = **розкладка** (генератор `gen_room.py` → `js/objects/arc_layout.js`, `NX.arcLayout`) → **нерухоме 3D** (рушій
`js/core/px3d.js`, сцена `js/objects/arc_scene.js`, матеріали `arc_kit.js`, малюнки граней `<зона>_paint.js`) → **живий шар**
зони поверх нього (`workshop.js`, `marketing.js`, `analytics.js`, `tools.js`). Історія кожного рішення (слова власника, кроки
1–12) — `docs/HISTORY.md`.

## Як малюємо зону
- **Розкладка.** Зона — набір частин у px картинки кімнати: `Z.add(id, X0, X1, Y0, Y1, v, d, стиль, …)` — прямокутник частини,
  `v` — відступ углиб від передньої лінії зони, `d` — глибина; `on='id'` — стоїть на іншій частині; `deco` — оздоби лиця;
  `cyl` + `kt`/`kb` — циліндр / зрізаний конус; `ch` — зрізані кути; `sty` — товщі фаска, шов, неоновий кант (`neon` — колір);
  `mirror(Z, id, …)` — частина й дзеркальна пара (`idL` / `idR`); `grp='ім'я'` — частини однієї групи не перевіряються на
  перетин (стільниця й її заокруглений кінець); `ghost=1` — **привид**: 3D його не малює й не бере в сліди, але `vcenter`
  вирівнює його по центру стола, а живий шар бере з нього базис (голо-панелі: `an_scr`, `tl_scr`); `fg=1` — **передній
  предмет** (річ на столі вища за низ живого екрана): рушій вирізає його окремим полотном, живий шар малює його поверх своїх
  екранів — `NX.arc.fgDraw(c, зона)`. `Z.anchor(ім'я, X, Y, v)` — точка для живого шару й Nexi; `Z.vc` — група частин за
  столом (будка, рамка з екранами) зсувається цілою, щоб на екрані бути по центру стола (якорі групи — `Z.vca`); вивіски
  `*_sign` — `sign_size`, однакові 150 × 30 на екрані для всіх зон. Головні частини зони — третій аргумент `Zone(...)`.
- **JS-доступ:** `NX.arc.zone(ім'я)` → `W(X, Y, v)` (світ), `S(X, Y, v)` (екран), `item(id)` (уже зі зсувом `vcenter`),
  `anchor(k)`, `m` (масштаб); `zoneBox` — межі зони на екрані `[x0, x1, y0, y1]` (тап, `span`).
- **3D-сцена** (`arc_scene.js`): шари крила (стіна й підлога → біля стіни → дальня → середня зона), збірка генератором під
  заставкою (`bootG`), злиття під масштаб екрана + сяйво (bloom), передня підлога-дзеркало. Головні зони — 4 px/од.
  (`R_HERO`), решта — 3, стіни — 2. **Сліди на підлозі:** зона, чий перед стоїть там, де ходять, реєструє `foot_<зона>` —
  Nexi й кіт обходять, тап у зону — Nexi стає перед нею. Підлоги крил сходяться під вікном.
- **Матеріали** (`arc_kit.js`, `NX.arc.kit.STY`): `desk`, `screen`, `frame`, `board`, `neon`, `shelf`, `dark`, `base`, `glass`…;
  зона додає свої у своєму `*_paint.js` (`chrome`, `mug` — аналітика; `brushed`, `toolbox`, `gantry`, `pod` — інструменти).
- **Малюнки граней** — у файлі зони (`ws_`, `mk_`, `an_`, `tl_paint.js`): `NX.arc.paint[id] = (c, fw, fh, B, F) => {…}` (c уже в
  одиницях грані fw × fh), бічні — `.sides = { top, bottom, left, right, back, side }` (`side` — смуга на кожному сегменті
  циліндра); спільне «залізо» — `NX.arc.pt` (`inset`, `bolt`, `led`, `vent`, `glass`, `drawer`…); вивіска — `signPlate`.
  Оживають самі, щойно в розкладці з'являється предмет з таким id.
- **Живі грані** — `NX.arc.LIVE[id] = { every, draw(c, fw, fh, t, B) }` (`arc_live.js` кладе їх у перспективу під маскою
  видимих пікселів): малюють лише те, що рухається; оновлюються раз на `every` кадрів вразбіг (лічильник свій для кожного
  крила), поза екраном не оновлюються й не кладуться; `draw` повертає `false` — грань зараз порожня (`NX.arc.glint` —
  відблиск вивіски між проходами).
- **Форми** — `NX.arc.shape[id | 'st:стиль']` з набором `G` (`P`, `sub`, `part`, `partF`, `tube`, `disc`,
  `face(poly, O, Au, Bv, shade, n)` — довільна пласка грань): `st:brace`, `st:cable` (інструменти), `an_pens` (аналітика).
  Співпадні грані (заокруглений кінець і стільниця) — верх циліндра на волосину нижче, щоб не мерехтіли.
- **Живий шар зони** — окремий об'єкт (`NX.addObject`): `span` / `hit` з `zoneBox`, `drawBack` (живе поверх нерухомого),
  місця для Nexi (`pad`, `stand`, `seat`…), `begin(task)` / `finish()`; сценарій — `activities.js`, задачі — `ui/zones.js`.
  Майстерня: голограма, голо-панелі `HPANES` (вміст `NX.arc.wsPane` у полотно раз на 3 кадри; «лаг» — `lagOf`), реліквії,
  маніпулятор (2D-ланки в площині лиця). Маркетинг: голо-монітори (`NX.furn.warp`), клавіатура, сердечка, картки.
- **Пласкі голо-панелі** (`holo_panes.js`): `NX.arc.holo.pane({zone, item, Xc, X, Y, v | dv, rgb, seed, paint, every, lagMin,
  shade, crisp, face, hinge})` — прямокутник у px картинки зони перед лицем предмета (зазвичай привида); вміст — пласке
  полотно (комп'ютер 1.5 px/од., телефон до 4), перемальовується раз на `every` кадрів (за замовчуванням 4) і кладеться в
  перспективу ~28 смужками; поза екраном (телефон) — не перемальовується, а повернувшись — той самий кадр (так само голо-
  панелі майстерні й монітори маркетингу: свої панелі зони варто робити так само); `crisp` — чіткий обрис (підкладка за обрисом, `shade` — її щільність), `hinge: {X, a}` — крило на
  петлі, `face` — лицем до глядача й симетрично на екрані; лаг — `p.kick(t, dur, kind)` (зона вирішує коли: одна панель за
  раз); `NX.arc.holo.at(зона, предмет, Xc, dv)` — точка на лиці → екран (дешеві дрібниці поверх: імпульси, промені, сяйво).
  **Обмеження:** панелі — поверх нерухомого злиття, тож перед ними не має стояти нерухомих предметів (або вони `fg=1`); те,
  що за панелями (сяйво, промені), живий шар малює до панелей.
- **Гоночне крісло** — 3D-модель px3d під кут повороту (кадр через 4°; кеш: R 4 у спокої, грубший R 2 під час обертання), два
  шари — позаду й попереду Nexi; хрестовина стоїть (`BASE_TURN`), спинка — профіль `PROF` (висота `HS`). Модель одна —
  фабрика `NX.arc.raceChair(cfg)` (`mk_chair.js`, там же крісло маркетингу; аналітика — `an_chair.js`): `zone`, `at` (px
  картинки зони), `K`, `HS`, `rest` (кут спокою), `colors`, `align`, `hitW`, `id` / `loc` / `obj`. Нове крісло — один виклик.
- **Перевірки:** генератор друкує `INTERSECT` і `BEHIND WALL` (мають бути `none`), `SEP` (проміжки між зонами на екрані > 0),
  лінію підлоги під передом кожної зони, розміри столів (`desk …`), якорі. Ходу перевіряли сотнями точок уздовж крил — жодного
  заходу в сліди. Знімки — нижче; дія Nexi + fps — `node tools/shot.js marketing 9000`.

## Файли

| Файл | Що робить |
|---|---|
| `gen_room.py` | генератор: стіни-дуги + зони з частин у 3D; перевірки; план зверху; `--write` пише в `js/objects/arc_layout.js` |
| `plan.py` | геометрія: проєкція кімнати `P3`, грані `faces`, слід `footprint`, роздільна лінія `sep`, крива `catmull` |
| `shot.js` | знімки з `dist/nexora-lab.html` (коли 3D зібралось): комп'ютер, кімната, ліве / праве крило, телефон 390×844, список об'єктів |
| `layout.json` | остання розкладка (те саме, що вшито в `arc_layout.js`; локально, у git не комітимо) |

## Як користуватись

```bash
python3 tools/wingbox/gen_room.py --plan /tmp/plan.png --write   # розкладка + план + записати в js/objects/arc_layout.js
python3 tools/build.py                                          # зібрати dist/
node tools/wingbox/shot.js /tmp/s desk roomc zoomL zoomR ph     # знімки (/tmp/s_desk.png …)
node tools/wingbox/shot.js /tmp/p desk --hash lang-pl           # те саме іншою мовою
node tools/wingbox/shot.js /tmp/x roomc --layout my.json         # спробувати іншу розкладку без --write і без збірки
node tools/wingbox/shot.js /tmp/c desk ph --clean 1             # без бабла Nexi (PHX='[["ph1",385],["ph2",900]]' — телефон на зонах)
python3 tools/wingbox/gen_room.py /tmp/a3.json --preset all3    # нинішні параметри з усіма трьома зонами: чи вмістяться наступні
```

Генератор друкує для кожного крила масштаби, висоти зон на екрані, проміжок кожної зони до стіни (`wall gap`), проміжки між
зонами на екрані (`SEP`), `INTERSECT` і `BEHIND WALL` і які колони не влізли між зонами (тоді їх немає).

## Геометрія

- Перспектива як у кімнаті (`js/core/persp.js`): точка сходу VP (774, 220), D 520, око (774, 220, −520); світ — x вправо,
  y вниз (підлога 372), z углиб (0 — площина картинки).
- Вікно — `NX.cfg.WIN` у `js/core/config.js` (508..1040, центр 774). Генератор читає його звідти; відкоси стоять на глибині
  z 185. Диван на плані — там, де він у кімнаті (`NX.cfg.SOFA_Y`).
- Кімната зверху — пів кола: від відкосу коротка пряма стіна до `xf` (1200), далі дуга (центр C = (xf, 185 − R), R 225) до
  глядача. Ліва стіна — дзеркало правої відносно x 774. План — `--plan`.
- Зони — ЛАНЦЮЖКОМ уздовж стіни від вікна: дальня (біля вікна) — спиною до стіни з вікном, **фронтально** (`far.fv` 1:
  `frontal` — зсув x + K·(z − z0), K = (xc − 774) / (D + z0): зона виглядає так, ніби око прямо перед її серединою; у кожного
  предмета `sh = [K, z0]`, рушій зсуває грані — `arc_kit.js basis`, `plan.py frame`); середня — `mid` (нижче); найближча —
  спиною до дуги й лицем до її центру (`chain`), впритул до попередньої. Нічого не заходить одне на одне.

## Параметри (`DEFAULT` унизу `gen_room.py` або `--params файл.json`)

- `R`, `xf` — радіус дуги й де починається дуга (225, 1200).
- `H` — висоти головних частин зон на екрані (px) по позиціях `[дальня, середня, найближча]` — зараз `[240, 300, 135]`; масштаб
  кожної зони підбирається під свою висоту (`fit_far` / `fit_chain` / `fit_front`).
- У крила (`right` / `left`):
  - `n` — скільки зон ланцюжка будувати (0..3): праворуч майстерня → інструменти → портал, ліворуч маркетинг → аналітика →
    AI-центр. Зараз `n` 2. `zones` — імена заготовок (`BUILDERS`; за замовчуванням нові).
  - `far.X_in` — край дальньої зони біля дивану (екранний x — найближча до середини точка зони), `far.gap` — найменший
    проміжок до стіни з вікном, `far.front` — лінія підлоги під передом зони на екрані (майстерня — 355), `far.fv` 1 — фронтально.
  - `mid` — середня зона: зараз `{"turn": 20, "fv": 1.25, "gs": -6}` (`front_items`) — намальована, ніби ми стоїмо перед нею
    (фронтальний зсув; `fv` > 1 — око трохи назовні), і повернута на `turn`° до середини кімнати: ближчий кінець зони
    зовнішній — видно ЗОВНІШНІЙ бік; `gs` — свій проміжок на екрані до дальньої (< 0 — трішки заходить на неї). Без `fv` — у
    перспективі кімнати (`arc_items`, видно внутрішній бік); `{"fv": 1}` без `turn` — просто фронтально.
  - `gz` / `gs` — проміжок до попередньої зони (у плані, од. світу / на екрані, px), `gw` — до стіни.
  - за потреби: `cols` — колони між зонами (лише якщо влазять). Антресоль, підвіси, полиці з вазонами й екран на стіні спроби
    28.10 (і відхилені пресети середніх зон arc / front / turn6) — в історії git (коміт a431f03).
- Зони: `workshop()`, `marketing()`, `analytics()`, `tools()`; заготовки 28.10 для наступних — `aicenter()`, `portal()`.
  `Z.arm` / `Z.armv` — маніпулятор майстерні
  (точки в px картинки, глибина) → розкладка `armRig` (малює й рухає його 2D-ланками `js/objects/workshop.js`).
