# Nexora AI · Лабораторія Nexi

Жива 8-bit кімната (2.5D + піксельне 3D). AI-помічник **Nexi** живе й працює в кімнаті: у маркетингу сідає в гоночне крісло й
пише пости та запускає рекламу, в аналітиці робить звіти на великому екрані, в інструментах на ранці підключає CRM і
календар, у майстерні міряє скіни (17 готових — від звичайних до легендарних) і збирає реліквії (вони кружляють навколо
голограми); відпочиває на дивані, милується містом за панорамним вікном, танцює, грається з рудим котом **Рудиком**. Емоції
показує сам; меблі обходить.

Стан, правила й план — **`docs/HANDOFF.md`** (паспорт); як малюємо зони — `tools/wingbox/README.md`; історія кроків —
`docs/HISTORY.md`.

## Запуск

```bash
python3 -m http.server 8000      # будь-який статичний сервер -> http://localhost:8000 (так само віддає сайт Vercel)
python3 tools/build.py           # або один файл без сервера -> dist/nexora-lab.html (локально, у git не комітимо)
```

## Технології

| Що | Чим |
|---|---|
| Мова | чистий JavaScript (ES2020), без фреймворків і збірки; скрипти підключаються по черзі в `index.html` |
| Графіка | HTML5 Canvas 2D: піксель-арт кодом; стіни, підлога й зони крил — власний програмний 3D-растеризатор з z-буфером (`js/core/px3d.js`) |
| Інтерфейс | HTML + CSS поверх canvas (`css/hud.css`) |
| Шрифти | Google Fonts: Press Start 2P, Rubik, JetBrains Mono — не блокують показ; заставка має свій піксельний шрифт кодом |
| Мови | власний мінімальний i18n (`js/core/i18n.js`), словники `js/i18n/` (uk — базова, en, pl, nl) |
| Інструменти | Python 3 (`tools/build.py`, генератор розкладки), Node + Playwright (знімки, заміри) |

## Як влаштована сцена

- **Запуск — під вітальною заставкою** (`index.html` → `js/ui/splash.js` → `js/main.js`): заставка видна одразу, лоад-бар
  показує справжні етапи; місто, 3D-крила й перший кадр будуються генераторами дрібними шматками (кожен `yield` — пауза для
  браузера), тож сторінка не «замерзає».
- **Координати = одиниці кімнати 1536 × 368** (`NX.cfg.ROOM_W/H`): `y < 0` — добудована стеля, `y > 368` — передня підлога.
  Перспектива одна: точка сходу (774, 220), D 520; 3D-світ — x вправо, y вниз (підлога 372), z углиб.
- **Комп'ютер:** уся кімната по ширині екрана, зайва висота стає стелею й підлогою. **Телефон:** кімната по висоті (видно
  ~п'яту частину), гортаємо пальцем, тап — Nexi йде туди; камера стежить за Nexi.
- **Кадр** (`js/core/loop.js`): оновлення → стеля й кімната → місто (лише коли видно вікно) → `drawBack` об'єктів (стіни й
  зони крил, рама, живі шари зон) → віддзеркалення в підлозі (лише в прямокутнику навколо персонажів) → шари `layers()`
  об'єктів і персонажів, відсортовані за глибиною `y` (так диван чи крісло закривають того, хто за ними) → частинки.
  Об'єкт зі `span` поза видимою смугою не малюється.
- **3D-крила:** розкладка (`arc_layout.js`) → растри шарів у px3d (z-буфер, контур, віддзеркалення) → злиття під масштаб
  екрана з сяйвом → щокадру один `drawImage` на крило + живі грані й живі шари зон поверх.
- **Обхід меблів:** об'єкт каже, де стоїть на підлозі, — `foot: [x0, x1, y0, y1]`; Nexi й кіт ходять `NX.room.route()` —
  найкоротшим шляхом через кути слідів.
- **Тексти** — лише зі словників (`NX.t`, `NX.pick`, `NX.num` — числа з десятковим знаком мови), і ті, що намальовані в
  сцені; запечене в растр перебудовується при зміні мови (`NX.i18n.onLang`). Мова — телефону / збережена; перевірка —
  адреса `#lang-en`, `#lang-pl`, `#lang-nl`. Нова мова — скопіювати `en.js`, перекласти й додати код у `NX.i18n.LANGS`.

## Як додати нову взаємодію (приклад: холодильник)

1. `js/objects/fridge.js` — `NX.addObject({ id: 'fridge', name: 'obj.fridge', act: 'snack', hit: {...}, foot: [x0, x1, y0, y1], layers(t) {...} })`
   (`foot` — де стоїть на підлозі: Nexi й кіт обходитимуть його самі).
2. `js/core/config.js → POI.fridge` — точка, де стає Nexi.
3. `js/actors/nexi/activities.js` — сценарій `snack: { route() { return [{ walk: ... }, { work: { pose: 'drink', dur: 4 } }]; } }`.
4. Тексти в усіх 4 словниках `js/i18n/*.js`: `obj.fridge`, `act.snack: { title, steps, lines }`.
5. Підключити файл в `index.html`. Інші файли не змінюються.

Робочі зони малюються інакше — 3D-розкладкою + малюнки граней + живий об'єкт зони: `tools/wingbox/README.md`.
