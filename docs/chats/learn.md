**Модулі (10).** Реалізовано: JavaScript (центральна вежа) · Canvas 2D (оранжерея під склепінням і піксельне табло) ·
HTML, CSS і Web API (східчастий блок із сонячними панелями) · Локалізація (тарілки й 4 щогли — по одній на мову) ·

Git, GitHub і Vercel (ангар із кораблем, дерево гілок). Заплановано — світними каркасами: Дані та API · AI · Застосунок.

**Як влаштовано (`src/`).**

- `data/registry.json` — реєстр реалізацій: що зроблено, якими файлами підтверджено, статус. Веде цей чат зі слова власника.
- `tools/scan.js <клон nexora-lab>` → `data/tech.json`: рахує файли й рядки, перевіряє докази, рівень росту модуля,
  звіт `report` (нові файли, зниклі докази, ознаки запланованих технологій, невідомі типи файлів).
- `tools/build.js` → `dist/index.html` (один файл); `tools/shot.js` — знімки комп'ютера й 390×844, консоль, заміри.
- Ріст: рівень модуля 1–3 від кількості підтверджених реалізацій (1 / 4 / 7), не зменшується; правила — `src/GROWTH.md`.
- Форма кожного модуля — `js/mod_<id>.js` (у шапці написано, що додає кожен рівень і які боти там працюють).

- «Актуальне» перевіряти пошуком на дату уроку, а не з пам'яті; називати версію й джерело.

## Словник
- **HTML / CSS / JS** — каркас сторінки / її вигляд / її поведінка (програма).
- **Canvas** — «полотно» в сторінці, на якому JS малює пікселі; уся кімната — один canvas `#world`.
- **Піксель-арт кодом** — картинку не вантажимо файлом, а малюємо командами (приклад — `js/objects/sofa.js`).
- **Перспектива, точка сходу** — точка, куди сходяться лінії вглиб; у Nexora (774, 220).
- **Кадр, fps** — одна перемальована картинка; fps — скільки кадрів за секунду (ціль ≥ 30).
- **Анімаційний цикл** — нескінченне «оновив стан → намалював» (`requestAnimationFrame` у `js/core/loop.js`).
- **i18n** — багатомовність: тексти лежать у словниках за ключами (`NX.t('nav.ai')`), а не в коді.
- **Генератор (Python)** — програма, що сама пише код чи дані (розкладку зон) замість ручної роботи.
- **Збірка (build)** — склеїти всі файли в один готовий (`dist/nexora-lab.html`).
- **Playwright** — робот, що відкриває сайт у браузері, робить знімки й ловить помилки.
- **Git / коміт / push** — журнал змін / один запис у ньому / надсилання записів на GitHub.
- **GitHub** — сховище коду в інтернеті. **Vercel** — хостинг: після push у `main` сам оновлює сайт.
- **Статичний сайт** — лише файли, без сервера з базою даних; Nexora зараз саме така.
