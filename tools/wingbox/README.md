# tools/wingbox — схема крил у 3D (сірий макет)

Інструменти, якими проєктуємо обидва крила кімнати в справжньому 3D у перспективі кімнати. Розкладка (`js/objects/arc_layout.js`,
`NX.arcLayout`) — спільна для схеми (`js/objects/rwing_box.js`) і для піксельного 3D (`js/objects/arc_scene.js`, адреса `#rw-3d`).
На сайті (гілка `rw-arc`) видно лише з адресою:

- `#rw-box` — схема з зонами (коробки, циліндри, листя з квітами, оздоби на гранях, написи з `NX.t`);
- `#rw-base` — лише основа: стіни й підлога крил по дузі, без зон (видно, що лишається: диван, підлога, вікно, рами);
- `#rw-3d` — те саме в піксельному 3D (рушій `js/core/px3d.js`, матеріали й малюнки — `js/objects/arc_*.js`; див. docs/HANDOFF.md).

## Файли

| Файл | Що робить |
|---|---|
| `gen_room.py` | генератор: зони з частин картинки `assets/room.webp` → 3D по дузі; крок 15%; перевірки; план зверху; `--write` пише в `js/objects/arc_layout.js` |
| `plan.py` | геометрія: проєкція кімнати `P3`, грані `faces`, слід `footprint`, роздільна лінія `sep`, крива `catmull` |
| `shot.js` | знімки з `dist/nexora-lab.html`: комп'ютер, кімната, ліве / праве крило, телефон 390×844, список об'єктів (`--hash rw-box` / `rw-base` / `rw-3d`) |
| `layout.json` | остання розкладка (те саме, що вшито в `rwing_box.js`) |

## Як користуватись

```bash
python3 tools/wingbox/gen_room.py --plan /tmp/plan.png --write   # розкладка + план + записати в js/objects/arc_layout.js
python3 tools/build.py                                          # зібрати dist/
node tools/wingbox/shot.js /tmp/s desk roomc zoomL zoomR ph     # знімки схеми (/tmp/s_desk.png …)
node tools/wingbox/shot.js /tmp/b roomc --hash rw-base           # лише основа
node tools/wingbox/shot.js /tmp/p desk zoomL zoomR ph --hash rw-3d   # піксельне 3D (shot.js сам чекає, поки зберуться шари)
node tools/wingbox/shot.js /tmp/x roomc --layout my.json         # спробувати іншу розкладку без --write і без збірки
```

Генератор друкує для кожного крила масштаби, висоти зон на екрані (має бути 100 / 85 / 72 %), проміжок кожної зони до стіни
(`wall gap`), проміжки між зонами на екрані (`SEP`: головні частини / усе — мають бути > 0, щоб зони не зливались),
`INTERSECT` (перетини об'ємів) і `BEHIND WALL` (що стоїть за стіною) — обидва мають бути `none`.

## Геометрія (домовленості з власником)

- Перспектива як у кімнаті (`js/core/persp.js`): точка сходу VP (774, 220), D 520, око (774, 220, −520); світ — x вправо,
  y вниз (підлога 372), z углиб (0 — площина картинки).
- Вікно — `NX.cfg.WIN` у `js/core/config.js` (зараз 508..1040, центр 774). Генератор читає його звідти; відкоси стоять
  на глибині z 185.
- Кімната зверху — пів кола: від відкосу коротка пряма стіна до `xf`, далі дуга (центр C = (xf, 185 − R), R 225) до
  глядача. Ліва стіна — дзеркало правої відносно x 774. План — `--plan`.
- Зони стоять спиною до стіни (власник, 28.10: «екрани — ближче до стіни, зони окремо»): дальня (біля вікна) — прямо,
  спиною до стіни з вікном (`far_place`: `gap` до стіни, `X` — середина на екрані, `kx` 1.15 — ширша, заходить за диван);
  середня й найближча — спиною до дуги (`wall_place`: `a` — кут на дузі, `gap` 4 — до стіни, `turn` — поворот: середня
  24° / −21° — фронтальніше, у перспективі кімнати; найближча 77° / −79° — показує внутрішній бік). Крок 15%: висота головних
  частин на екрані 230 / 196 / 166 (`HP`, ·0.85, ·0.85²).
- Диван у `#rw-3d` стоїть ближче до глядача (`NX.cfg.SOFA_Y3D` — лінія підлоги на екрані); на плані — там само.
- Кожна зона — частини картинки: `Z.add(id, X0, X1, Y0, Y1, v, d, стиль, …)` — прямокутник частини на картинці,
  відступ углиб `v` і глибина `d` (у пікселях картинки). `on='id'` — стоїть на іншій частині; `cyl` — циліндр;
  `plant` + `fw`/`fh` — листя (`hangs` — звисає, `bloom` — квіти); `deco` — оздоби на передній грані (частки грані).
- Праве крило технологічне (майстерня, інструменти, портал, екран NEXORA AI, антресоль, колона-опора антресолі),
  ліве — затишне (маркетинг, аналітика, AI-центр зі стелажем; настінні полиці з вазонами, квітами, плющем, книжками).
  Параметри розміщення — `DEFAULT` унизу `gen_room.py` (або `--params файл.json`).
