# Nexora AI · Лабораторія Nexi

Жива 8-bit кімната (2.5D + піксельне 3D). AI-помічник **Nexi** живе й працює в кімнаті: сідає в гоночне крісло маркетингу й пише
пости та запускає рекламу, злітає в капсулу майстерні й міряє скіни (17 готових — від звичайних до легендарних; маніпулятор їх
«встановлює») і бере в руки реліквії зі своєї колекції (громовий молот, лазерний меч, золота рукавиця, щит Nexi, екскалібур…; вони
кружляють навколо голограми), відпочиває й працює з планшетом на дивані, милується містом за панорамним вікном, танцює, грається
з рудим котом **Рудиком**. Емоції показує сам; меблі обходить, а не ходить по них.

> **29.10 — чиста основа** (власник: «почнемо все з 0»): диван, вікно з містом, віконні рами, підлога й стіни; робочі зони
> (AI-центр, аналітика, маркетинг, майстерня, інструменти, портал) додаються по черзі. **Зараз — майстерня (скіни: капсула-
> сканер, голограма Nexi в різних скінах, живий маніпулятор) і маркетинг (будка з голо-екраном, голо-монітори, крісло, що
> обертається); обидві фронтально, і Nexi в обох уже працює.** Крок 3: 10 нових предметів у руки, гоночне крісло, «живий» екран
> маркетингу (мерехтіння, глітч, сповіщення), обхід меблів. Крок 4: обличчя не вибирається — емоції Nexi показує сам; реліквії
> (предмети в руці) окремо від аксесуарів і на орбіті навколо голограми; 17 готових скінів із рідкістю; планшет «Аксесуари»;
> крісло більше, рівне, з новими ніжками. **Кроки 5–9: аналітика — «обсерваторія даних»** (скляний стіл із заокругленим
> кінцем, тумба й серверна стійка, між ними простір для ніг із «трубою даних»; пласкі голо-панелі ВІДВІДУВАЧІ й ВИРУЧКА,
> голо-діаграма над проєктором, радар-тарілка, кава з парою) **та інструменти — «майстерня інтеграцій»** (верстак на козлах з
> помаранчевими розпірками, ящик і кабель на полиці, хаб з антеною, лещата з іскрами, маячок; бурштинові голо-картки ПОШТА ·
> КАЛЕНДАР · CRM, АВТО й API) — ближчі до глядача, трохи повернуті до центру (20°) — видно їхній зовнішній бік; вужчі, щоб по
> краях лишилось місце для AI-центру й порталу; голо-екрани зрідка глючать; Nexi в них — наступним кроком.
> Правки зон · 1: у крісла маркетингу одне коліщатко на промінь (було подвійне), хрестовина стоїть — крутиться лише верх.
> Правки зон · 2: панелі СКІНИ й АКСЕСУАРИ в майстерні — голограми без рамки (довші й ширші, світять із проєкторів на
> платформі); реліквії — лазерний меч, щит Nexi з «N», золота рукавиця (власні дизайни).
> Правки зон · 3: голо-панелі менш прозорі й насиченіші, раз на 4–9 с коротко «лагають» (завис, смуги, розходження кольорів).
> Правки зон · 4: у крісла маркетингу вища спинка (у ~1.6 раза) — пропорції справжнього гоночного крісла.
> **Заставка · 1: вітальна заставка замість чорного екрана** — з'являється миттєво, лоад-бар показує справжні етапи (скрипти →
> картинка кімнати → місто → 3D-крила → готово), піксельний Nexi, підписи піксельним шрифтом 4 мовами, кімната будується
> дрібними шматками, у кінці Nexi злітає на свій док; три варіанти оформлення — `#splash-a` / `#splash-b` / `#splash-c`.
> Стан і план — **`docs/HANDOFF.md`**.
> Усе, що було до того, — в історії git: коміт `a941612` (останній стан із зонами; `da12467` — сайт до 29.10).

| Що | Чим |

## Запуск

```bash
# варіант 1: будь-який статичний сервер
python3 -m http.server 8000      # і відкрити http://localhost:8000
# варіант 2: один файл без сервера
python3 tools/build.py           # -> dist/nexora-lab.html, відкрити в браузері
```

## Як влаштована сцена

- **Запуск — під вітальною заставкою** (`index.html` → `js/ui/splash.js` → `js/main.js`): заставка видна одразу, лоад-бар
  показує справжні етапи; місто, 3D-крила й перший кадр будуються генераторами дрібними шматками (кожен `yield` — пауза для
  браузера), тож сторінка не «замерзає». Нова важка збірка при завантаженні — теж генератором (див. `docs/HANDOFF.md`,
  «Вітальна заставка й запуск»).
- **Система координат = пікселі картинки кімнати (1536 × 368 од.).** `y` від 0 до 368 — картинка, `y < 0` — добудована стеля,
  `y > 368` — добудована передня підлога.
- **Перспектива одна:** точка сходу (774, 220), D 520; 3D-світ — x вправо, y вниз (підлога 372), z углиб.
- **Десктоп:** уся кімната по ширині екрана, зайва висота стає стелею й підлогою. **Телефон:** кімната по висоті, гортаємо
  пальцем, тап — Nexi йде туди.
- **Глибина:** що нижче на екрані, то ближче; персонажі масштабуються (`NX.room.scaleAt`), усе сортується за `y` перед
  малюванням. Об'єкт віддає шари `layers() → [{y, draw}]` — так диван закриває того, хто за ним.
- **Обхід меблів:** об'єкт може сказати, де він стоїть на підлозі, — `foot: [x0, x1, y0, y1]` (диван, крісло, куточок кота);
  Nexi й кіт ходять не навпростець, а `NX.room.route()` — найкоротшим шляхом через кути слідів (спереду меблів).

### Мови — `js/i18n/`
`uk.js` (базова), `en.js`, `pl.js`, `nl.js`. Українська — за замовчуванням; для перевірки — адреса `#lang-en`, `#lang-pl`,
`#lang-nl` (`#lang-uk` — назад). **Усі тексти — лише зі словників**, і ті, що намальовані в сцені: написи на екранах і табличках
— `scene.*`, вивіски й реклама міста — `city.*`, aria-підказки — `ui.*`; числа з десятковим знаком мови — `NX.num(v, d)`.
Тексти зон (`act.<зона>`, `zones.*`, `nav.*`, `obj.*`, `portal.*`) лишились у словниках — для зон, що повертаються.
Щоб додати мову — скопіювати `en.js`, перекласти й додати код у `NX.i18n.LANGS`.

## Як додати нову взаємодію (приклад: холодильник)

1. `js/objects/fridge.js` — `NX.addObject({ id: 'fridge', name: 'obj.fridge', act: 'snack', hit: {...}, foot: [x0, x1, y0, y1], layers(t) {...} })`
   (`foot` — де стоїть на підлозі: Nexi й кіт обходитимуть його самі)
2. `js/core/config.js → POI.fridge` — точка, де стає Nexi.
3. `js/actors/nexi/activities.js` — сценарій `snack: { route() { return [{ walk: ... }, { work: { pose: 'drink', dur: 4 } }]; } }`
4. Тексти в усіх 4 словниках `js/i18n/*.js`: `obj.fridge`, `act.snack: { title, steps, lines }`.
5. Підключити файл в `index.html`. Інші файли не змінюються.

Робочі зони малюються інакше — 3D-розкладкою (`tools/wingbox/gen_room.py` → `arc_layout.js` → `arc_scene.js`) + малюнки граней
(`*_paint.js`) + живий об'єкт зони (`workshop.js`, `marketing.js`), див. `docs/HANDOFF.md`.
