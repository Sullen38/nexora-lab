# Nexora AI · Лабораторія Nexi

Жива 8-bit кімната (2.5D), в якій AI-помічник **Nexi** працює з об'єктами самої кімнати:
злітає ранцем на стіл і друкує за комп'ютером, сідає в крісла біля екранів, варить каву,
читає на дивані, спить під пледом, стає на сканер скінів, ремонтує панель на ранці,
заходить у портал. Поруч живе рудий кіт **Рудик**: спить, їсть, грається, приходить до Nexi.

## Технології

| Що | Чим |
|---|---|
| Мова | чистий JavaScript (ES2020), без фреймворків |
| Графіка | HTML5 Canvas 2D, піксельне малювання кодом (спрайти не картинками, а `fillRect`) |
| Фон кімнати | `assets/room.webp` (1536×368) — очищена картинка з концепту |
| Інтерфейс | HTML + CSS поверх canvas |
| Шрифти | Google Fonts: Press Start 2P, Rubik, JetBrains Mono |
| Збірка | не потрібна; `tools/build.py` (Python 3) склеює все в один HTML |

## Запуск

```bash
# варіант 1: будь-який статичний сервер
python3 -m http.server 8000      # і відкрити http://localhost:8000
# варіант 2: один файл без сервера
python3 tools/build.py           # -> dist/nexora-lab.html, відкрити в браузері
```

## Як влаштована сцена

- **Система координат = пікселі картинки кімнати.** `y` від 0 до 368 — сама картинка,
  `y < 0` — добудована стеля, `y > 368` — добудована передня підлога.
- **Десктоп:** уся квартира по ширині екрана, зайва висота стає стелею й підлогою.
  **Телефон:** кімната по висоті, гортаємо пальцем, тап — Nexi йде туди.
- **Глибина (2.5D):** що нижче на екрані, то ближче. Персонажі й передні предмети
  масштабуються (`NX.room.scaleAt`, `NX.px.depth`), а все сортується за `y` перед малюванням.
- **Перекриття:** кожен об'єкт віддає шари `layers() → [{y, draw}]`. Тому спинка крісла
  закриває Nexi, коли він сидить, а плед лежить поверх нього, коли він спить.

## Карта файлів: що за що відповідає

### Ядро — `js/core/`
| Файл | Відповідає за |
|---|---|
| `namespace.js` | глобальний об'єкт `NX`, реєстр об'єктів |
| `config.js` | константи і **всі точки взаємодії** (`POI`): де стіл, крісла, диван, портал… |
| `pixel.js` | інструменти 8-bit малювання: куб 2.5D, світіння, голо-панель, текст, перспектива |
| `camera.js` | масштаб під екран, добудова стелі/підлоги, перетягування пальцем, тапи |
| `loop.js` | головний цикл: оновлення → малювання шарами → сортування за глибиною |

### Світ — `js/world/`
| Файл | Відповідає за |
|---|---|
| `room.js` | картинка кімнати + добудована стеля + глянцева підлога з відображенням; межі ходіння |
| `ambient.js` | життя фону: вікна міста, зорі, планета, корабель, екрани, лампи |

### Об'єкти кімнати — `js/objects/` (кожен — окремий незалежний блок)
| Файл | Об'єкт | Що з ним робить Nexi |
|---|---|---|
| `taskboard.js` | дошка задач на стіні | показує поточну й виконані задачі |
| `ai_pc.js` | комп'ютер AI-центру | злітає ранцем на стіл і друкує |
| `office.js` | крісла + екрани аналітики й маркетингу | сідає спиною до нас, екрани оживають |
| `coffee.js` | кавомашина | варить і п'є каву |
| `sofa.js` | диван (з картинки) + плед | сидить і читає / спить |
| `workshop.js` | сканер скінів | стає на платформу, відкривається лабораторія скінів |
| `tools.js` | перфодошка, ящик, панель інтеграцій | висить на ранці й ремонтує |
| `portal.js` | вихор + пульт | заходить у портал і повертається |
| `cat_corner.js` | лежанка, дряпка, миски, м'ячик | насипає корм |
| `rug_dock.js` | килим і док-станція | заряджається вдома |
| `arcade.js` | ігровий автомат | грає у вільний час |
| `lounge.js` | пуф, столик, торшер | сидить на пуфі |
| `plants_front.js` | рослини на передньому плані | — (глибина сцени) |

### Персонажі — `js/actors/`
| Файл | Відповідає за |
|---|---|
| `nexi/skins.js` | каталог скінів (тільки дані) |
| `nexi/sprite.js` | малювання Nexi по пікселях, вигляд спереду і ззаду, ранець |
| `nexi/poses.js` | пози й анімації (ходьба, друк, сидіння, політ, сон…) |
| `nexi/nexi.js` | мозок: черга дій, вихід з місць, вільний час, малювання в кімнаті |
| `nexi/activities.js` | **сценарії взаємодії** для кожної зони |
| `cat/cat_sprite.js` | малювання рудого кота |
| `cat/cat.js` | поведінка кота (голод, сон, ігри, стрибки) |

### Інтерфейс — `js/ui/` і `css/hud.css`
| Файл | Відповідає за |
|---|---|
| `input.js` | тапи/кліки: Nexi → скіни, кіт → погладити, об'єкт → сценарій, підлога → іти |
| `hud.js` | меню, чип задачі, бабл над Nexi, підказка, тост |

| `main.js` | старт застосунку |

## Як додати нову взаємодію (приклад: холодильник)

1. `js/objects/fridge.js` — `NX.addObject({ id:'fridge', name:'Холодильник', act:'snack', hit:{...}, layers(t){...} })`
2. `js/core/config.js → POI.fridge` — точка, де стає Nexi.
3. `js/actors/nexi/activities.js` — сценарій `snack: { title, steps, route(){ return [{walk:...},{work:{pose:'drink',dur:4}}] } }`
4. Підключити файл в `index.html`. Інші файли не змінюються.

- Скіни зберігаються в `localStorage` — для акаунтів потрібен бекенд.
