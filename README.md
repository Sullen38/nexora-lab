# Nexora AI · Лабораторія Nexi

Жива 8-bit кімната (2.5D). AI-помічник **Nexi** працює з об'єктами самої кімнати:
злітає ранцем на стіл і друкує за комп'ютером, сідає в крісла біля екранів, варить каву,
читає на дивані, спить під пледом, стає на сканер скінів, ремонтує панель на ранці,
заходить у портал. Поруч живе рудий кіт **Рудик**: спить, їсть, грається, приходить до Nexi.

## Технології

| Що | Чим |
|---|---|
| Мова | чистий JavaScript (ES2020), без фреймворків |
| Графіка | HTML5 Canvas 2D, піксельне малювання кодом (спрайти не картинками, а `fillRect`) |
| Фон кімнати | `assets/room.webp` (3072×736, збільшено нейромережею EDSR ×2) — очищена картинка з концепту |
| Інтерфейс | HTML + CSS поверх canvas |
| Шрифти | Google Fonts: Press Start 2P, Rubik, JetBrains Mono |
| Мови | власний мінімальний i18n (`js/core/i18n.js`), словники в `js/i18n/` |
| Збірка | не потрібна; `tools/build.py` (Python 3) склеює все в один HTML |

## Документи

- **`docs/HANDOFF.md`** — паспорт проєкту: правила, статус об'єктів, як починати новий чат.
- `tools/image/README.md` — як оброблялась картинка кімнати.
- `tools/shot.js` — швидка перевірка в браузері (скриншот + fps + помилки).

## Запуск

```bash
# варіант 1: будь-який статичний сервер
python3 -m http.server 8000      # і відкрити http://localhost:8000
# варіант 2: один файл без сервера
python3 tools/build.py           # -> dist/nexora-lab.html, відкрити в браузері
```

## Як влаштована сцена

- **Система координат = пікселі картинки кімнати.** `y` від 0 до 368 — сама картинка,
  `y < 0` — добудована стеля, `y > 368` — добудована передня підлога.
- **Десктоп:** уся квартира по ширині екрана, зайва висота стає стелею й підлогою.
  **Телефон:** кімната по висоті, гортаємо пальцем, тап — Nexi йде туди.
- **Глибина (2.5D):** що нижче на екрані, то ближче. Персонажі й передні предмети
  масштабуються (`NX.room.scaleAt`, `NX.px.depth`), а все сортується за `y` перед малюванням.
- **Перекриття:** кожен об'єкт віддає шари `layers() → [{y, draw}]`. Тому спинка крісла
  закриває Nexi, коли він сидить, а плед лежить поверх нього, коли він спить.

## Карта файлів: що за що відповідає

### Ядро — `js/core/`
| Файл | Відповідає за |
|---|---|
| `namespace.js` | глобальний об'єкт `NX`, реєстр об'єктів |

| `persp.js` | перспектива кімнати: точка сходу, коробки в перспективі (`box`), екрани на стіні (`wall`); `NX.persp.desk` — пологіша перспектива для меблів |

| `camera.js` | масштаб під екран, добудова стелі/підлоги, перетягування пальцем, тапи |
| `loop.js` | головний цикл: оновлення → малювання шарами → віддзеркалення в підлозі → сортування за глибиною |

## Як додати нову взаємодію (приклад: холодильник)

1. `js/objects/fridge.js` — `NX.addObject({ id:'fridge', name:'Холодильник', act:'snack', hit:{...}, layers(t){...} })`
2. `js/core/config.js → POI.fridge` — точка, де стає Nexi.
3. `js/actors/nexi/activities.js` — сценарій `snack: { route(){ return [{walk:...},{work:{pose:'drink',dur:4}}] } }`
4. Тексти в `js/i18n/*.js` → `act.snack: { title, steps, lines }`
5. Підключити файл в `index.html`. Інші файли не змінюються.
