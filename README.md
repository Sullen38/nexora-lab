# Nexora AI · реклама (`Sullen38/nexora-promo`)

Окремий проєкт: скріншоти, банер, відео й тексти для App Store і Google Play, ролики для соцмереж — «Впізнай всесвіт Nexi».
**Гру не змінюємо ніяк:** `Sullen38/nexora-lab` лише клонуємо для зйомки (`.cache/nexora-lab`, push вимкнено); сценою
керуємо ззовні — Playwright, наявні функції гри (`NX.ui.chat.go`, `NX.guests.spawn`, `NX.virus.spawn`, `NX.cam`…) і час.

## Стан
- **Чат «Реклама · 1» закрито власником (04.11).** Репозиторію `Sullen38/nexora-promo` ще немає, тож цей код **тимчасово —
  у гілці `promo` репозиторію `Sullen38/nexora-lab`** (окрема історія; у `main` гри нічого не додано). Коли `nexora-promo`

  git push https://github.com/Sullen38/nexora-promo promo:main`, далі працювати там, а гілку `promo` у грі видалити
  (`git push https://github.com/Sullen38/nexora-lab --delete promo`). **Чекає «так»:** план нижче і вибір стилю A / B / C
  (або мікс). Ще не зроблено — кроки 2–8 плану. Підсумок для інших чатів — `docs/HISTORY.md` гри, «Реклама · 1».
  Ескізи знято з гри `fa0c620` (02.11); кімната відтоді змінилась — перед кроком 2 перезняти (`bash tools/setup.sh`,
  `node shots/sketch_raw.js <мова>`, `node shots/sketch.js uk,en,pl,nl`, `node shots/overview.js`).
- **Реклама · 1 — огляд, план, стенд зйомки, 3 ескізи стилю (02.11) — чекає «так» і вибору стилю A / B / C.**

  `banner_{a,b,c}.png` (Google Play 1024×500); аркуші огляду — `out/sketches/overview_{uk,gp,langs,banners}.png`
  (там і en / pl / nl; самі файли en / pl / nl — `node shots/sketch.js uk,en,pl,nl`, у git не кладемо).
  Знято з гри `fa0c620` (02.11). Тексти — чернетка (`copy/sketch.json`).

  що в сирому кадрі (без масштабування); усі 27 файлів — точний розмір, RGB без прозорості; написи 4 мовами влазять (pl, nl —
  найдовші); у кадрі — без цін, значків магазинів і рамок пристроїв; консоль гри без помилок.

Чому так: стиль — основа всього; скріншоти потрібні для подачі першими й задають сцени; банер і іконка — для сторінки
Google Play і збірки застосунку; відео — найважчі, але беруть сцени зі скріншотів; тексти — коли зрозуміло, що вже вміє
застосунок.

### Відео — як знімаємо
Кадр за кадром: фальшивий годинник і фіксоване зерно (як `tools/same.js` у грі), 1 кадр відео = 2 кадри гри (1/30 с),
знімок → ffmpeg (H.264, рівно 30 кадрів/с, звукова доріжка). Дубль повторюється піксель у піксель, тож коли кімната зміниться
— просто перезапускаємо. Написи — PNG-шари з тих самих макетів (поверх кадрів, App Store це дозволяє); заставок із логотипом
у прев'ю App Store не буде (лише кадри застосунку). Музика — твоя або з ліцензією; без неї — тиха доріжка.

## Ескізи стилю (Реклама · 1)
- **A «Неонова вивіска»** — підпис у вивісці, як вивіски зон у кімнаті (Press Start 2P), стеля з неоном; банер — кімната,
  NEXORA AI у вивісці, Nexi махає, Рудик.
- **B «Слово Nexi»** — Nexi говорить сам: бабл, як у грі (темний, блакитна рамка), хвостик — на Nexi; банер — великий Nexi
  й бабл «Привіт! Я Nexi…».
- **C «Голо-рамка»** — по-діловому: великий заголовок Rubik, кадр гри у світній рамці; банер — заголовок ліворуч, живий кадр
  AI-центру праворуч.

Спільне: кадр гри — справжній, 1:1 (без масштабування); підпис — у смузі зверху ≤ 20 % висоти (вимога Google, так само
й для Apple); кольори й шрифти — з гри; без значків магазинів, рамок пристроїв, цін, «№1 / найкращий / новий / безкоштовно»
і закликів «Завантаж!». Можна змішувати (напр. смуга A + бабл B у сцені з Nexi).

## Як зняти й зібрати
```bash
bash tools/setup.sh            # клон гри (лише читання) + шрифти з github.com/google/fonts → .cache/
node shots/sketch_raw.js uk    # сирі кадри гри: out/raw/sketch/uk/ (en | pl | nl — так само)
node shots/sketch.js uk,en,pl,nl   # ескізи → out/sketches/<мова>/
node shots/overview.js         # аркуші перегляду
node rig/raw.js zone --o '{"zone":"marketing"}' --dpr 1   # огляд будь-якої сцени (кадри щосекунди)
```
- `rig/game.js` — гра з клону: локальний сервер (як `tools/bench.js`), шрифти — перехоплення запитів Google Fonts і файли з
  `google/fonts`, годинник і випадковість під контролем, кадр гри = 1/60 с. **Чіткість:** гра обмежує полотно до 2× (на 3×
  телефоні браузер розтягує з розмиттям) — стенд малює полотно в повній роздільності екрана (лише чіткість, сцена та сама).
  Растри кімнати гра будує не більше ніж 4 пікселі на одиницю кімнати — тому кадр App Store займає 80 % висоти (2295 з 2868):
  на всю висоту було б 4,64 → піксель-арт «поплив би». Звідси й смуга з підписом.
- `scenes/index.js` — сцени: зона (`NX.ui.chat.go` — як тап по зоні), скіни, гість (`NX.guests.spawn`), вірус (`NX.virus.spawn`),
  камера на телефоні (`NX.cam.x` — як перетягування пальцем).
- `layouts/*.html` + `render/compose.js` — макети в PNG точного розміру; перевірка: розмір, RGB без прозорості, текст не вилазить.
- `copy/*.json` — тексти 4 мовами (uk — основна, en, pl, nl). Мова гри в кадрі — `#lang-xx`, тож і інтерфейс у кадрі тією ж мовою.
- Кожен сирий кадр має `.json` поруч: коміт гри, кадр, де Nexi.

## Правила магазинів (перевірено 02.11.2026)
- **Apple:** 6.9″ — 1320×2868 (або 1290×2796 / 1260×2736), 1–10 шт., PNG / JPEG; знімки показують застосунок у роботі, можна
  написи поверх (2.3.3); прев'ю — лише записи екрана застосунку, можна написи й голос (2.3.4); 886×1920, 15–30 с, ≤ 30 кадрів/с;
  покупки в застосунку в кадрі — чітко позначити (2.3.2); без цін у знімках і прев'ю (2.3.7); без назв і значків інших
  платформ — жодного Android / Google Play у матеріалах для Apple (2.3.10).
- **Google Play:** банер 1024×500, JPEG / 24-біт PNG без прозорості, головне — по центру, без пристроїв, значків магазинів,
  чужих логотипів, «Best / #1 / New / Free», цін і знижок, без «на час» (свята, акції); скріншоти — справжній застосунок,
  2–8, 320–3840 px, довша сторона ≤ 2× коротшої, підпис ≤ 20 % кадру, без закликів («Завантаж зараз»), окремі для кожної мови;
  відео — YouTube, без реклами, публічне / за посиланням, не 18+, застосунок у перші 10 с, ≥ 80 % — сам застосунок,
  портрет без чорних смуг.
- Джерела: [Apple — скріншоти](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications) ·
  [Apple — прев'ю](https://developer.apple.com/help/app-store-connect/reference/app-information/app-preview-specifications) ·
  [App Review Guidelines 2.3](https://developer.apple.com/app-store/review/guidelines/) ·
  [Google Play — графіка й відео](https://support.google.com/googleplay/android-developer/answer/9866151)

## Ризики
- Зараз у кімнаті все «бізнесове» — демо: остаточні знімки й відео — з застосунку (крок 8); до того обіцянок у підписах — лише
  про те, що буде в етапі 1 (відповіді, листи, підсумки, пости, реклама, розсилки — чернетки).
- Персональний Nexi в кадрі — лише коли покупка в застосунку справді працює (Apple — лише через покупки Apple).
- Кімната ще змінюється (паралельні чати гри) — усе знімається скриптами; у метаданих кадрів — коміт гри.
