# Nexora AI · Лабораторія Nexi

Жива 8-bit кімната (2.5D + піксельне 3D). AI-помічник **Nexi** живе й працює в кімнаті: відпочиває й працює з планшетом на
дивані, милується містом за панорамним вікном, танцює, грається з рудим котом **Рудиком**, міняє скіни в лабораторії.

> **29.10 — чиста основа** (власник: «почнемо все з 0»): у кімнаті лише диван, вікно з містом, віконні рами, підлога й стіни;
> робочі зони (AI-центр, аналітика, маркетинг, майстерня, інструменти, портал) додаються по черзі. Стан і план — **`docs/HANDOFF.md`**.
> Усе, що було до того, — в історії git: коміт `a941612` (останній стан із зонами; `da12467` — сайт до 29.10).

## Технології

| Що | Чим |
|---|---|
| Мова | чистий JavaScript (ES2020), без фреймворків |
| Графіка | HTML5 Canvas 2D: піксель-арт кодом (`fillRect`, растри), стіни й підлога крил — власний програмний 3D-растеризатор з z-буфером (`js/core/px3d.js`) |
| Фон | `assets/room.webp` (3072×736) — очищена картинка з концепту `assets/src/concept.webp`; майже все поверх неї вже намальовано кодом |
| Інтерфейс | HTML + CSS поверх canvas |
| Шрифти | Google Fonts: Press Start 2P, Rubik, JetBrains Mono |
| Мови | власний мінімальний i18n (`js/core/i18n.js`), словники в `js/i18n/` (uk, en, pl, nl) |
| Збірка | не потрібна; `tools/build.py` (Python 3) склеює все в один HTML |

## Документи

- **`docs/HANDOFF.md`** — паспорт проєкту: правила, що зараз у кімнаті, як малюємо зони, план, текст для нового чату.
- `tools/wingbox/README.md` — генератор розкладки крил «по дузі», план зверху, знімки.

## Запуск

```bash
# варіант 1: будь-який статичний сервер
python3 -m http.server 8000      # і відкрити http://localhost:8000
# варіант 2: один файл без сервера
python3 tools/build.py           # -> dist/nexora-lab.html, відкрити в браузері
```

## Як влаштована сцена

- **Система координат = пікселі картинки кімнати (1536 × 368 од.).** `y` від 0 до 368 — картинка, `y < 0` — добудована стеля,
  `y > 368` — добудована передня підлога.
- **Перспектива одна:** точка сходу (774, 220), D 520; 3D-світ — x вправо, y вниз (підлога 372), z углиб.
- **Десктоп:** уся кімната по ширині екрана, зайва висота стає стелею й підлогою. **Телефон:** кімната по висоті, гортаємо
  пальцем, тап — Nexi йде туди.
- **Глибина:** що нижче на екрані, то ближче; персонажі масштабуються (`NX.room.scaleAt`), усе сортується за `y` перед
  малюванням. Об'єкт віддає шари `layers() → [{y, draw}]` — так диван закриває того, хто за ним.

### Мови — `js/i18n/`
`uk.js` (базова), `en.js`, `pl.js`, `nl.js`. Українська — за замовчуванням; для перевірки — адреса `#lang-en`, `#lang-pl`,
`#lang-nl` (`#lang-uk` — назад). **Усі тексти — лише зі словників**, і ті, що намальовані в сцені: написи на екранах і табличках
— `scene.*`, вивіски й реклама міста — `city.*`, aria-підказки — `ui.*`; числа з десятковим знаком мови — `NX.num(v, d)`.
Тексти зон (`act.<зона>`, `zones.*`, `nav.*`, `obj.*`, `portal.*`) лишились у словниках — для зон, що повертаються.
Щоб додати мову — скопіювати `en.js`, перекласти й додати код у `NX.i18n.LANGS`.

## Як додати нову взаємодію (приклад: холодильник)

1. `js/objects/fridge.js` — `NX.addObject({ id: 'fridge', name: 'obj.fridge', act: 'snack', hit: {...}, layers(t) {...} })`
2. `js/core/config.js → POI.fridge` — точка, де стає Nexi.
3. `js/actors/nexi/activities.js` — сценарій `snack: { route() { return [{ walk: ... }, { work: { pose: 'drink', dur: 4 } }]; } }`
4. Тексти в усіх 4 словниках `js/i18n/*.js`: `obj.fridge`, `act.snack: { title, steps, lines }`.
5. Підключити файл в `index.html`. Інші файли не змінюються.

Робочі зони малюються інакше — 3D-розкладкою (`tools/wingbox/gen_room.py` → `arc_layout.js` → `arc_scene.js`), див. `docs/HANDOFF.md`.
