## Правила (не порушувати)
1. **Нічого не вирізати з картинки** — усе кодом, піксель-артом у стилі кімнати: неон, глянець, 8-bit перелив з дизерингом,
   темний контур, віддзеркалення в підлозі, без розмиття. Еталон якості — `js/objects/sofa.js`.
2. **Меню зон немає — Nexi сам бере задачі по черзі** (`NX.ui.zones.pick`, пам'ять у localStorage) і показує картку
   результату; побутове (диван) — зважений рандом (`sofa.pick`). Кнопок зон теж немає (02.11): у шапці лише назва.
3. **Усі тексти — лише через словники `js/i18n/*.js`, одразу 4 мови** (uk — за замовчуванням; en, pl, nl), і ті, що
   НАМАЛЬОВАНІ в сцені (вивіски, екрани, таблички, журнали, одиниці й десятковий знак — `NX.num`). Рядків у код не вписувати.
   Без перекладу — лише NEXORA, NEXI, AI, KPI, CRM, API, коди мов. Написи мають вміщатись у будь-якій мові (найдовші — pl).
   Текст, запечений у растр, перебудовується при зміні мови (`NX.i18n.onLang(f)`). Перевірка — `#lang-en`, `#lang-pl`, `#lang-nl`.
4. **Одна перспектива на все:** точка сходу VP (774, 220), D 520, око (774, 220, −520); світ: x — вправо, y — вниз (підлога
   372), z — углиб (0 — площина картинки, стіна з вікном — z 185). Персонажі ростуть за `NX.room.scaleAt` (ближче — більші).
5. **Після змін:** `python3 tools/build.py` → перевірка (знімки комп'ютер + телефон 390×844, консоль без помилок, fps) →
   оновити цей файл (свій рядок у «Стан») і `docs/HISTORY.md` (докладно), README — якщо змінилась карта файлів → коміт і push.
6. **Швидкодія** (ціль ≥ 30 fps): нерухоме — один раз у растр і злиття в одне полотно під масштаб екрана; жодних
   повноекранних проміжних полотен щокадру; щокадру — лише живе (екрани — раз на кілька кадрів); `shadowBlur` вимкнено
   глобально (`pixel.js`); об'єкт зі `span: [x0, x1]` поза видимою смугою не малюється (телефон бачить ~п'яту частину кімнати);
   без `clip()` за складною формою на великих шарах; багато вогників — кешовані спрайти, не градієнт щоразу. **Важке при
   завантаженні — генератором з `yield`** (як `arc_scene.js`, `cityscape.js`), інакше заставка «замерзне».
7. **Емоції Nexi показує сам** — вираз обличчя не вибирається (`nexi.js`: `FACE`, `moodLife`); у лабораторії скінів — лише стиль.

## Як працюємо
- **Один чат — один крок** (одна зона чи одна правка): довгі чати швидко витрачають ліміт. Код і рішення — у репозиторії,
  цей файл — пам'ять між чатами (коротко), `docs/HISTORY.md` — подробиці.
- Власник надсилає одним повідомленням скриншот із позначками + що має бути. Claude робить → перевіряє → **коміт і push у
  `main`** (зміни одразу на сайті) → показує знімки й **чекає «так»**, перш ніж робити далі.
- **Кілька чатів паралельно** (правки зон, заставка, нові зони, загальний): перед роботою й перед кожним комітом —
  `git pull --rebase origin main`; файли, які зараз правлять інші чати (видно з `git log`), без потреби не чіпати; згенерований
  `js/objects/arc_layout.js` при конфлікті руками не зливати — злити `tools/wingbox/gen_room.py` і перезібрати
  (`python3 tools/wingbox/gen_room.py --write`). `dist/` і `tools/wingbox/layout.json` — лише локально, у git не комітимо.
- **Загальний чат:** оптимізація (fps, запуск, розмір), чистка (мертвий код, невикористані файли й ключі словників,
  дублікати), документи й тексти для нових чатів; зон не малює, вигляду й поведінки не змінює — доводить це `tools/same.js`.
  Дрібні коміти (одна чистка — один коміт), заміри до й після — в описі коміту; push — пачками (менше деплоїв Vercel).
- **Інструменти перевірки** (спершу `python3 tools/build.py` — знімки беруть `dist/`):
  - `node tools/shot.js [дія] [мс]` — дія Nexi + знімок + fps; `node tools/wingbox/shot.js /tmp/s desk roomc zoomL zoomR ph` —
    знімки зон (`--hash lang-pl`, `--clean 1`); `node tools/splash/shot.js /tmp/sp abc wings:.55 uk` — знімки заставки;
  - `node tools/same.js [коміт]` — знімки до/після піксель у піксель (робоча копія проти `HEAD`; годинник і випадковість
    сторінки підмінені, тож кадри порівнянні); `node tools/bench.js [коміт] --dev desk|ph --cpu 1|4` — заміри (запуск,
    fps по місцях, на що йде кадр; `--det 1` — обидві версії бачать ті самі кадри, для «до / після» правки; `--flush 1` —
    справжня ціна кожного шару: Chrome малює відкладено); `node tools/first.js [коміт] --runs 3` — перші секунди після заставки (fps, на що йде
    кадр у кадрах 0–90 і 90–240). Ці три віддають теку як сайт — збирати не треба. Ціни кадру між версіями порівнювати на
    одній машині: контейнер чату буває різний (ядер 2 або більше).

## Відомі проблеми / ідеї
- **Спрайт Nexi не віддзеркалюється, не нахиляється й не стискається** (з 23.10, коміт 036a915): `actors/nexi/physics.js` —
  пружина рахує `− o[v] * damp`, коли `o[v]` ще `undefined`, тож `sq`, `lean`, `ax`, `ay` — NaN. Виправлення — одне місце
  (`(o[v] || 0) * damp`), але воно змінить вигляд руху скрізь — **чекає рішення власника** (знайдено в «Декор стін · 6»).
- Інтерфейс поверх кімнати: прозорі контейнери (`.top`, `.chat`) — `pointer-events: none`, тапи ловлять лише кнопки й панелі
  (02.11: порожнє місце контейнера діалогу «з'їдало» тапи по передній підлозі на телефоні — Nexi туди не йшов).
- iPhone: свайп від краю екрана — жест Safari «назад» / «вперед» (власник 02.11: гортав кімнату — випадав зі сайту). Канвас
  біля країв (28 px) скасовує touchstart — Safari (iOS 13.4+) жест тоді не починає (`core/camera.js`). Жест вбудованих
  браузерів (Telegram, Instagram…) сайт не вимкне, але він часто — «назад» в історії: після дотику до кімнати в історії стоїть
  запасний крок на ту саму сторінку, тож випадковий «назад» лишає в кімнаті (вийти — «назад» двічі поспіль). Свайп по нижньому
  адресному рядку Safari (перемикає вкладки) з сайту не вимкнути.
- Хостинг: Vercel Hobby — лише некомерційне; коли Nexora почне продавати — Vercel Pro ($20 на місяць) або Cloudflare Pages
  (безкоштовно, трафік без ліміту, комерційне дозволене; адреса зміниться).
- Повторне відкриття могло б бути майже миттєвим — кеш зібраних растрів крил і міста (IndexedDB; ключ — версія + мова + масштаб).
