# Правила Nexora AI — для всіх чатів (з 13.11)

Читати на початку кожного чату. Це коротка версія; стара повна пам'ять — `docs/HANDOFF.md` (архів, 330 КБ): **цілим не читати**,
шукати потрібне через `grep -n "ключове слово" docs/HANDOFF.md`. Подробиці кроків — `docs/HISTORY.md` (теж через grep).

## Як працюємо
1. Репо `Sullen38/nexora-lab`, гілка `main`, сайт nexora-lab-six.vercel.app. Перед роботою й перед кожним комітом — `git pull --rebase origin main`.
2. **Кожен чат має свою сферу й свої файли** — `docs/OWNERS.md`. Чужі файли не правити; потрібна зміна в чужому — написати власнику
   проєкту, що саме й навіщо (він передасть у потрібний чат), або зробити мінімально за його прямим словом і записати в свій файл чату.
3. Спільні файли: `index.html` (лише свій рядок `<script>`), `js/i18n/*.js` (лише свої гілки ключів), `js/actors/nexi/activities.js`
   (лише свої дії окремим блоком). `js/objects/arc_layout.js` руками не правити — тільки `python3 tools/wingbox/gen_room.py --write` (3–4 хв).
4. Власник надсилає скрін із позначками й слова. Нову розкладку спершу показати схемою й чекати підтвердження. Зробив → перевірив →
   коміт і push у `main` → знімки (комп'ютер + телефон 390×844) → чекати «так».
5. Після кроку оновити **свій** файл `docs/chats/<чат>.md` (стан, що чекає «так») і `docs/HISTORY.md` (докладно). HANDOFF більше не доповнюємо.

## Правила вигляду й коду
1. Нічого не вирізати з картинок — уся графіка піксель-артом кодом у стилі кімнати (неон, глянець, темний контур). Еталон — `js/objects/sofa.js`.
2. Меню зон немає; Nexi сам бере задачі. Емоції Nexi показує сам.
3. Усі тексти — лише через `js/i18n/*.js`, одразу 4 мови (uk, en, pl, nl), зокрема намальовані в сцені. Без перекладу — NEXORA, NEXI, AI, KPI, CRM, API, NFT.
4. Одна перспектива: точка сходу (774, 220), D 520; підлога y 372.
5. Швидкодія (ціль ≥ 30 fps): нерухоме — раз у растр; щокадру лише живе; без `clip()` на великих шарах; кешовані спрайти; важке при
   завантаженні — генератором з `yield`.
6. Декор не заходить у робочі зони: `node tools/wingbox/decor_check.js` → `DECOR OVER ZONES … none`.
7. Історія світу — `docs/UNIVERSE.md`. Реклама — окремий проєкт, гру не змінює.
